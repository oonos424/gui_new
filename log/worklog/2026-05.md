# WorkLog — May 2026

## 2026-05-07 — Initial project scaffold (gui_new)

### What was done
Created the `gui_new` repository from scratch with the full build toolchain, adapted from
the existing `affrgui` reference project and the spec at `affrgui_spec/`.

### Decisions
- **Java 25 / JavaFX 25** instead of 21 — matches the to-be target in the spec.
- **VTK Java wrapper removed** — 3D viewer moves to Python/Trame subprocess accessed via JavaFX `WebView`; `javafx.swing` module excluded accordingly.
- **`temurin:25` / `liberica:25`** added as primary JVM candidates in `JavaEnv.bash` / `JavaEnv.ps1`; 21 kept as fallback.
- **Monaco resource path** changed from `jp.advancesoft.*` to `affr/app/editor/monaco/vs` to match the new package namespace.
- **FXML formatter** updated to `--jfx-version=25.0`; pre-commit Java/Kotlin formatters updated to `--jvm=temurin:25`.
- **Launch4j / JDK download tasks omitted** from `build.gradle.kts` for now — packaging is not the immediate concern; will be added when the build is stable.

### Open questions

- `trame_backend/` directory created but not yet populated.
